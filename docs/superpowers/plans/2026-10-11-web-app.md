# Zohar Symbols — Web App Implementation Plan (plan 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Flask web app that reads `data/zohar.sqlite` (built by plan 1) and serves the curious reader's path from the approved mockup: Home field → Symbol page → Node page / Tree → Passage page, plus Scholars and About, bilingual EN/ES. No model calls (Ask, translations and glosses are plan 3; the pages show their fallbacks).

**Architecture:** `web/` is a thin Flask package: one query module over read-only SQLite, one view module per page group, Jinja templates, one CSS file ported from the mockup, a strings catalogue for EN/ES, language carried in the URL prefix (`/es/…`). Everything heavy was precomputed by the pipeline; a page needs ≤ 1 query per section. Deploy on Render (Starter), building the database at deploy time from the pinned Wikisource revisions.

**Tech Stack:** Python 3.11, Flask 3, Jinja2, stdlib `sqlite3`, gunicorn, pytest + Flask test client. No JS framework; ~60 lines of vanilla JS for the kind filter and hover counts.

**Spec:** `docs/superpowers/specs/2026-10-11-zohar-symbols-design.md` (§6 web app, §7 Ask — fallbacks only, §8 translation — fallbacks only, §9 licensing/citation/i18n, §10 errors/tests). **Design reference:** mockup canvas https://claude.ai/artifact/LNcGFhBgXUKqs3SuxRB8RS (Home + Moon page); its colours and typefaces are copied verbatim in §Global Constraints.

## Global Constraints

- The LLM never produces a number. No model calls in this plan. Every count on a page is a column read from `data/zohar.sqlite`.
- Read-only database access: `sqlite3.connect(f"file:{path}?mode=ro", uri=True)`, `row_factory = sqlite3.Row`.
- Passage id format `{volume}.{folio:03d}{side}.{para:03d}` → `1.020a.003`. Citation display: `Zohar I:20a` (volume as Roman numeral I/II/III, folio + side).
- Language in the URL: EN at `/…`, ES at `/es/…`; a cookie `lang` remembers the last choice; never header-detected. UI strings from `web/strings.json` (`{"key": {"en": "...", "es": "..."}}`); content from `_en`/`_es` columns. Hebrew/Aramaic always `dir="rtl" lang="arc"`.
- Look (from the mockup, exact): ground `#12131C`, surface `#1B1D2A`, border `#2A2C3B`, text `#ECE6D8`, muted `#A39E90`, gold `#D9B36A`, blue (events) `#7FA7C9`, red (Sitra Aḥra) `#C98A7F`, moon-white `#E8E4F0`. Typefaces via Google Fonts: Cormorant Garamond (display), Source Sans 3 (body), Frank Ruhl Libre (Hebrew/Aramaic). Dark only. Phone layout: clusters stack, evidence strip below the claim, Aramaic above translation.
- Top partners shown to readers are ranked by `passages_together`; PMI appears only on the Scholars table and only for pairs with `passages_together >= 5`.
- Where a translation/gloss is absent (always, in this plan): translations show the string `not_translated`; glosses show the computed one-liner `"{label} · {count_passages} passages · appears alongside {top partner}"` built by code, not the model.
- Every page footer: attribution line (Hebrew Wikisource, CC BY-SA 4.0), `tables_version` from `meta`, link to Scholars.
- Never `git push`, never tag, never deploy. Commit locally only.
- Tests run with `uv run --no-sync pytest`.

## Review Focus

1. **A symbol with zero mentions** (`mouth_of_river`): its page must render (counts 0, no partners, "not yet found in the text"), not 500. → Task 4 `test_symbol_page_zero_mentions`.
2. **A passage id with a stream continuation** (e.g. a Ra'aya Meheimna paragraph `3.280b.040`) must render the stream label and its folio neighbours correctly; prev/next must stay within the same folio-side ordering. → Task 6 `test_passage_prev_next_within_folio`.
3. **The ES route for every page** must render with no English UI strings leaking (the strings catalogue is complete). → Task 8 `test_all_pages_in_es_have_no_untranslated_keys`.

```python
def compute_all(raw: dict, tokens: list[dict], mentions: list[dict], symbols: list[Symbol]) -> dict:
    """Everything compute.main writes, as one dict. Shared by main and the tests."""
    strata = assign_strata(raw["passages"], load_strata(ROOT / "seeds" / "strata.tsv"))
    cooc = cooccurrence(mentions, len(raw["passages"]))
    tbp = defaultdict(list)
    for t in tokens:
        tbp[t["passage_id"]].append(t)
    return dict(
        tables_version=TABLES_VERSION,
        cooccurrence=cooc,
        symbol_counts=resolve_counts(mentions, cooc, symbols),
        states=detect_states(mentions, tokens, symbols),
        strata=dict(sorted(strata.items())),
        surfaced={s.id: surfaced_passages(s.id, mentions, cooc, tbp, strata) for s in sorted(symbols, key=lambda s: s.id)},
    )
```

```python
"""Read-only access to data/zohar.sqlite, one connection per request."""
import sqlite3
from flask import current_app, g


def get_db() -> sqlite3.Connection:
    if "db" not in g:
        path = current_app.config["DB_PATH"]
        g.db = sqlite3.connect(f"file:{path}?mode=ro", uri=True, check_same_thread=False)
        g.db.row_factory = sqlite3.Row
    return g.db


def close_db(_exc=None) -> None:
    db = g.pop("db", None)
    if db is not None:
        db.close()


def one(sql: str, params: tuple = ()) -> sqlite3.Row | None:
    return get_db().execute(sql, params).fetchone()


def all(sql: str, params: tuple = ()) -> list[sqlite3.Row]:
    return get_db().execute(sql, params).fetchall()
```

**Interfaces (all return plain dicts/lists of dicts; all take `lang` where labels are involved):**
- `meta() -> dict` (tables_version, built_at, source_revids)
- `nodes_with_symbols(lang) -> list[dict]`: one entry per node in canonical order (`keter, hokhmah, binah, hesed, gevurah, tiferet, netzah, hod, yesod, malkhut, sitra_ahra, ein_sof`), each `{"node", "label", "label_ar", "symbols": [{"id","label","label_ar","kind","count_passages","size": 15..44}]}` where `size` is a font-size in px scaled by `count_passages` (log scale, min 15, max 44, computed in code).
- `symbol(sid, lang) -> dict | None`: `{id, label, label_ar, label_other (the other language), kind, node, node_label, aliases_surface, aliases_root, count_raw, count_resolved, count_passages, seed_source, gloss (gloss_xx or computed one-liner), moves (moves_xx or None)}`
- `partners(sid, k=7) -> list[dict]`: `{"id","label","passages_together","pmi"}` ordered by `passages_together` desc, then id.
- `states(sid) -> list[dict]`: from `state_decl` LEFT JOIN counts in `state`: `{"label","marker_roots","count"}`; plus `unmarked = count_passages - distinct passages in any state`.
- `strata_distribution(sid) -> list[dict]`: `{"stratum","count"}` over passages mentioning sid.
- `surfaced(sid, lang) -> list[dict]`: the ≤6 passages in rank order, each a passage card dict (see `passage()`).
- `passage(pid, lang) -> dict | None`: `{id, citation ("Zohar I:20a"), volume, folio, side, para, parasha, stream, stratum, text_ar, verse_ref, token_count, translation (text or None), mentions: [{"position","symbol_id","label","matched_form"}]}`
- `folio(volume, folio, side, lang) -> list[dict]`: every passage of that folio-side in `para` order (for the passage page's context and prev/next).
- `node(nid, lang) -> dict | None`: `{node, label, label_ar, pillar, symbols_by_kind: {kind: [symbol…]}, partner_nodes: [{"node","label","passages_together"}] (sum over symbol pairs across nodes)}`
- `search(q, lang, k=10) -> list[dict]`: symbols whose label (either language), label_ar, or any alias contains `q` (case-insensitive; Hebrew exact substring), ordered by count_passages.
- `nearest_symbols(q, k=3) -> list[dict]`: `difflib.get_close_matches` over ids + labels, for 404 suggestions.
- `scholars_pairs(min_together=5, limit=200) -> list[dict]`: pairs ordered by PMI desc.
- `cite.roman(volume) -> "I"|"II"|"III"`, `cite.citation(volume, folio, side) -> "Zohar I:20a"`, `cite.formats(meta) -> dict[str,str]` (bibtex, chicago, sbl) with the author, title "Zohar Symbols: a computed dictionary of the Zohar's kinnuyim", year, version, URL https://zohar.digital, and DOI placeholder `[DOI pending]` until a Zenodo DOI exists (the placeholder is deliberate and visible).

Key SQL, one function each:

```python
NODE_ORDER = ["keter","hokhmah","binah","hesed","gevurah","tiferet","netzah","hod","yesod","malkhut","sitra_ahra","ein_sof"]
PILLAR = {"hesed":"right","gevurah":"left","netzah":"right","hod":"left","hokhmah":"right","binah":"left"}  # others middle

def _lab(row, lang): return row[f"label_{lang}"] if row[f"label_{lang}"] else row["label_en"]

def _size(count, cmax):
    import math
    if count <= 0: return 15
    return int(round(15 + 29 * math.log1p(count) / math.log1p(max(cmax, 1))))

def nodes_with_symbols(lang):
    rows = all("select id,label_en,label_es,label_ar,kind,node,count_passages from symbol order by count_passages desc, id")
    cmax = rows[0]["count_passages"] if rows else 1
    by = {n: [] for n in NODE_ORDER}
    for r in rows:
        by[r["node"]].append(dict(id=r["id"], label=_lab(r, lang), label_ar=r["label_ar"], kind=r["kind"],
                                  count_passages=r["count_passages"], size=_size(r["count_passages"], cmax)))
    return [dict(node=n, label=t_node(n, lang), label_ar=NODE_AR[n], symbols=by[n]) for n in NODE_ORDER]

def partners(sid, k=7):
    return [dict(id=r["other"], label=None, passages_together=r["passages_together"], pmi=r["pmi"]) for r in all(
        """select case when symbol_a=? then symbol_b else symbol_a end as other, passages_together, pmi
           from cooccurrence where symbol_a=? or symbol_b=? order by passages_together desc, other limit ?""",
        (sid, sid, sid, k))]  # labels filled by a second small query over symbol ids

def states(sid):
    decl = all("select state_label, marker_roots from state_decl where symbol_id=? order by state_label", (sid,))
    counts = {r["state_label"]: r["n"] for r in all("select state_label, count(*) n from state where symbol_id=? group by state_label", (sid,))}
    marked = one("select count(distinct passage_id) n from state where symbol_id=?", (sid,))["n"]
    total = one("select count_passages n from symbol where id=?", (sid,))["n"]
    return dict(states=[dict(label=d["state_label"], marker_roots=d["marker_roots"], count=counts.get(d["state_label"], 0)) for d in decl],
                unmarked=max(0, total - marked))

def surfaced(sid, lang):
    ids = [r["passage_id"] for r in all("select passage_id from surfaced where symbol_id=? order by rank", (sid,))]
    return [passage(pid, lang) for pid in ids]

def passage(pid, lang):
    p = one("select * from passage where id=?", (pid,))
    if not p: return None
    ms = all("""select m.position, m.symbol_id, m.matched_form, s.label_en, s.label_es from mention m
                join symbol s on s.id=m.symbol_id where m.passage_id=? order by m.position""", (pid,))
    tr = one("select text from translation where passage_id=? and lang=?", (pid, lang))
    return dict(id=p["id"], citation=cite.citation(p["volume"], p["folio"], p["side"]), volume=p["volume"], folio=p["folio"],
                side=p["side"], para=p["para"], parasha=p["parasha"], stream=p["stream"], stratum=p["stratum"],
                text_ar=p["text_ar"], verse_ref=p["verse_ref"], token_count=p["token_count"],
                translation=tr["text"] if tr else None,
                mentions=[dict(position=m["position"], symbol_id=m["symbol_id"], matched_form=m["matched_form"], label=_lab(m, lang)) for m in ms])
```

# Zohar Symbols — Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the offline, deterministic pipeline that turns the Hebrew Wikisource Zohar into `data/zohar.sqlite`: passages, tokens with roots, symbol mentions, co-occurrences, states, strata, and the surfaced-passage selection.

**Architecture:** Six stages (`fetch → segment → lemmatise → tag → compute → build`), each a module with a pure function and a thin CLI, each writing one file the next reads. `aramaic_core` from the Atlas does root extraction; a Zohar override table wins when it matches. No model calls in this plan (translate/gloss are plan 3). No web code (plan 2).

**Tech Stack:** Python 3.11, `uv`, `requests`, `pytest`, SQLite (stdlib). `aramaic_core` as a git dependency on `Jossifresben/aramaic-root-atlas`.

**Spec:** `docs/superpowers/specs/2026-10-11-zohar-symbols-design.md` (§3 Architecture, §4 Data model, §5 Tagging and computation, §10 Errors/tests/rollout).

## Global Constraints

- The LLM never produces a number. Nothing in this plan calls a model.
- Pipeline is rerunnable and idempotent per stage: each stage reads the previous stage's file and writes its own; a stage never modifies an earlier stage's output.
- Every stage writes `report.md` beside its output (counts in/out, unknowns, top anomalies).
- Every output carries `TABLES_VERSION` (string, from `pipeline/version.py`).
- Passage id format: `{volume}.{folio:03d}{side}.{para:03d}` → `1.020a.003`.
- Base text: Hebrew Wikisource, parasha pages `זוהר חלק א` … `זוהר חלק ל`, Mantua pagination from `<קטע התחלה=דף X Y/>` markers. Revision ids recorded in `data/SOURCES.md`.
- Licence files: `LICENSE` (MIT), `LICENSE-DATA.md` (CC BY-SA 4.0 with Wikisource attribution).
- Never `git push`. Commit locally only.
- Python ≥ 3.11 (the Atlas requires it; system Python is 3.10, so use `uv venv --python 3.11`).

## Review Focus

1. **A folio marker with a typo or an unclosed section** (`<קטע התחלה=דף כ א/>` with no matching `<קטע סוף=…/>`): segment must raise naming the page and label, not silently merge two folios. → Task 4 test `test_unclosed_section_raises`.
2. **Words with proclitics** (`וסיהרא`, `דסיהרא`, `בסיהרא`): tag must still count them as mentions of Moon; a reader would expect "and the Moon" to count. → Task 7 test `test_proclitic_forms_match`.
3. **Inline variant readings** `(נ"א …)` / `(ס"א …)` inside the text: they must not be counted as text (they'd double-count symbols); a reader citing a folio expects the main reading. → Task 4 test `test_variant_readings_removed`.
4. **A symbol whose alias is also a common word** (ארץ "earth/land"): counts must show the raw total and the resolved total separately so the home field doesn't show Earth as the biggest symbol in the book. → Task 8 test `test_ambiguous_alias_raw_and_resolved`.
5. **Rerunning the pipeline on the same input** must produce byte-identical `tables.json` (ordering of dict keys, floating-point PMI formatting). → Task 10 test `test_determinism`.

# pipeline/hebnum.py
"""Hebrew numerals as Wikisource writes them: no geresh, טו/טז for 15/16."""

_VALUES = {
    "א": 1, "ב": 2, "ג": 3, "ד": 4, "ה": 5, "ו": 6, "ז": 7, "ח": 8, "ט": 9,
    "י": 10, "כ": 20, "ל": 30, "מ": 40, "נ": 50, "ס": 60, "ע": 70, "פ": 80, "צ": 90,
    "ק": 100, "ר": 200, "ש": 300, "ת": 400,
}
_HUNDREDS = [(400, "ת"), (300, "ש"), (200, "ר"), (100, "ק")]
_TENS = [(90, "צ"), (80, "פ"), (70, "ע"), (60, "ס"), (50, "נ"), (40, "מ"), (30, "ל"), (20, "כ"), (10, "י")]
_ONES = "אבגדהוזחט"


def heb_to_int(s: str) -> int:
    if not s or any(c not in _VALUES for c in s):
        raise ValueError(f"not a Hebrew numeral: {s!r}")
    return sum(_VALUES[c] for c in s)


def int_to_heb(n: int) -> str:
    if n <= 0 or n >= 1000:
        raise ValueError(f"out of range: {n}")
    out = ""
    for v, c in _HUNDREDS:
        while n >= v:
            out += c
            n -= v
    if n == 15:
        return out + "טו"
    if n == 16:
        return out + "טז"
    for v, c in _TENS:
        if n >= v:
            out += c
            n -= v
            break
    if n:
        out += _ONES[n - 1]
    return out
```

# pipeline/wikisource.py
"""Fetch one Hebrew Wikisource page's wikitext with its revision id, cached on disk."""
import hashlib
import json
from dataclasses import dataclass, asdict
from pathlib import Path

import requests

API = "https://he.wikisource.org/w/api.php"
UA = "zohar-symbols/0.1 (https://github.com/Jossifresben/zohar-symbols)"


@dataclass(frozen=True)
class PageText:
    title: str
    revid: int
    timestamp: str
    wikitext: str


def _cache_path(cache_dir: Path, title: str) -> Path:
    return cache_dir / (hashlib.sha1(title.encode("utf-8")).hexdigest() + ".json")


def fetch_page(title: str, cache_dir: Path, session=None) -> PageText:
    cache_dir.mkdir(parents=True, exist_ok=True)
    cp = _cache_path(cache_dir, title)
    if cp.exists():
        return PageText(**json.loads(cp.read_text(encoding="utf-8")))
    session = session or requests.Session()
    r = session.get(API, params={
        "action": "query", "prop": "revisions", "titles": title,
        "rvprop": "ids|timestamp|content", "rvslots": "main", "format": "json",
        "formatversion": "1",
    }, timeout=60)
    r.raise_for_status()
    pages = r.json()["query"]["pages"]
    page = next(iter(pages.values()))
    if "missing" in page or "revisions" not in page:
        raise LookupError(f"Wikisource page not found: {title}")
    rev = page["revisions"][0]
    pt = PageText(title=page["title"], revid=int(rev["revid"]),
                  timestamp=rev["timestamp"], wikitext=rev["slots"]["main"]["content"])
    cp.write_text(json.dumps(asdict(pt), ensure_ascii=False), encoding="utf-8")
    return pt
```

Set a `User-Agent` on real sessions: in `fetch_page`, if `session is None`, do `session.headers["User-Agent"] = UA` after creating it.

```python
# pipeline/segment.py
"""Wikitext of a parasha page → passages keyed by Mantua folio and paragraph."""
import re
from dataclasses import dataclass

from .hebnum import heb_to_int

BOOKS = {"בראשית": "Genesis", "שמות": "Exodus", "ויקרא": "Leviticus",
         "במדבר": "Numbers", "דברים": "Deuteronomy"}

_START = re.compile(r"<קטע התחלה=דף ([א-ת]+) ([אב])/>")
_END = re.compile(r"<קטע סוף=דף ([א-ת]+) ([אב])/>")
_MM = re.compile(r"\{\{ממ\|([^|}]+)\|([א-ת]+)(?:\|([א-ת]+))?\}\}")
_TZ = re.compile(r"\{\{צ\|([^}]*)\}\}")
_SHIN = re.compile(r"\{\{ש\}\}")
_ANY_TEMPLATE = re.compile(r"\{\{[^{}]*\}\}")
_VARIANT = re.compile(r"\((?:נ\"א|ס\"א|נ״א|ס״א)[^)]*\)")
_LINK = re.compile(r"\[\[[^\]]*\]\]")
_TAG = re.compile(r"</?(?:small|big|br|ref|span|div)[^>]*>")
_BOLD = re.compile(r"'''?")
_WS = re.compile(r"[ \t]+")


class SegmentError(Exception):
    def __init__(self, page_title: str, label: str, reason: str):
        super().__init__(f"{page_title}: section {label!r}: {reason}")
        self.page_title, self.label, self.reason = page_title, label, reason


@dataclass(frozen=True)
class Passage:
    id: str
    volume: int
    folio: int
    side: str
    para: int
    parasha: str
    text_ar: str
    verse_ref: str | None


def _verse_ref(block: str) -> str | None:
    m = _MM.search(block)
    if not m:
        return None
    book = BOOKS.get(m.group(1).strip())
    if not book:
        return None
    ch = heb_to_int(m.group(2))
    if m.group(3):
        return f"{book} {ch}:{heb_to_int(m.group(3))}"
    return f"{book} {ch}"


def clean_wikitext(s: str) -> str:
    s = _VARIANT.sub("", s)
    s = _TZ.sub(lambda m: m.group(1), s)
    s = _SHIN.sub("\n\n", s)
    s = _ANY_TEMPLATE.sub("", s)
    s = _ANY_TEMPLATE.sub("", s)  # nested once more
    s = _LINK.sub("", s)
    s = _TAG.sub("", s)
    s = _BOLD.sub("", s)
    s = _WS.sub(" ", s)
    return "\n".join(line.strip() for line in s.split("\n")).strip()


def _paragraphs(block: str) -> list[str]:
    cleaned = clean_wikitext(block)
    paras = [p.strip() for p in re.split(r"\n\s*\n", cleaned)]
    return [p.replace("\n", " ") for p in paras if p]


def segment_page(wikitext: str, volume: int, parasha: str, page_title: str) -> list[Passage]:
    passages: list[Passage] = []
    pos = 0
    while True:
        m = _START.search(wikitext, pos)
        if not m:
            break
        label = f"{m.group(1)} {m.group(2)}"
        e = _END.search(wikitext, m.end())
        nxt = _START.search(wikitext, m.end())
        if not e or (nxt and nxt.start() < e.start()):
            raise SegmentError(page_title, label, "unclosed section")
        if (e.group(1), e.group(2)) != (m.group(1), m.group(2)):
            raise SegmentError(page_title, label, f"closed by {e.group(1)} {e.group(2)}")
        block = wikitext[m.end():e.start()]
        folio = heb_to_int(m.group(1))
        side = "a" if m.group(2) == "א" else "b"
        vref = _verse_ref(block)
        for i, text in enumerate(_paragraphs(block), start=1):
            passages.append(Passage(
                id=f"{volume}.{folio:03d}{side}.{i:02d}", volume=volume, folio=folio,
                side=side, para=i, parasha=parasha, text_ar=text, verse_ref=vref))
        pos = e.end()
    return passages
```

Note on `verse_ref`: the first `{{ממ|book|ch|v}}` in the folio block names the verse under comment for every passage of that folio. Good enough for v1; the spec says "where detectable".

# pipeline/fetch.py
"""Fetch every parasha page from Wikisource and segment into passages."""
import argparse
import csv
import json
from dataclasses import asdict
from datetime import datetime, timezone
from pathlib import Path

from .report import write_report
from .segment import segment_page
from .version import TABLES_VERSION
from .wikisource import PageText, fetch_page

ROOT = Path(__file__).resolve().parent.parent
RAW = ROOT / "raw"
DATA = ROOT / "data"


def load_parashot(path: Path) -> list[dict]:
    with path.open(encoding="utf-8") as f:
        rows = list(csv.DictReader(f, delimiter="\t"))
    for r in rows:
        r["volume"] = int(r["volume"])
    return rows


def build_raw(pages: list[tuple[str, int, str, PageText]]) -> dict:
    out = {"tables_version": TABLES_VERSION,
           "fetched_at": datetime.now(timezone.utc).isoformat(timespec="seconds"),
           "pages": [], "passages": []}
    for title, volume, parasha, pt in pages:
        out["pages"].append({"title": title, "revid": pt.revid, "timestamp": pt.timestamp,
                             "volume": volume, "parasha": parasha})
        out["passages"] += [asdict(p) for p in segment_page(pt.wikitext, volume, parasha, title)]
    return out


def write_sources_md(out: dict, path: Path) -> None:
    lines = ["# Sources", "", f"Fetched {out['fetched_at']} from https://he.wikisource.org (CC BY-SA 4.0).", "",
             "| page | revid | timestamp |", "|---|---|---|"]
    lines += [f"| {p['title']} | {p['revid']} | {p['timestamp']} |" for p in out["pages"]]
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text("\n".join(lines) + "\n", encoding="utf-8")


def main(argv=None) -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--only", type=int, default=None, help="fetch only the first N parasha pages")
    args = ap.parse_args(argv)
    rows = load_parashot(ROOT / "seeds" / "parashot.tsv")
    if args.only:
        rows = rows[:args.only]
    pages = [(r["page_title"], r["volume"], r["parasha"], fetch_page(r["page_title"], RAW / "cache"))
             for r in rows]
    out = build_raw(pages)
    RAW.mkdir(exist_ok=True)
    (RAW / f"zohar.v{TABLES_VERSION}.json").write_text(json.dumps(out, ensure_ascii=False), encoding="utf-8")
    write_sources_md(out, DATA / "SOURCES.md")
    folios = {(p["volume"], p["folio"], p["side"]) for p in out["passages"]}
    write_report(RAW / "report.md", "fetch", [
        ("pages", len(out["pages"])), ("folios", len(folios)), ("passages", len(out["passages"])),
        ("empty passages", sum(1 for p in out["passages"] if not p["text_ar"])),
    ])


if __name__ == "__main__":
    main()
```

# pipeline/lemmatise.py
"""Tokens with roots: aramaic_core's extractor, overridden by seeds/zohar_overrides.tsv."""
import argparse
import csv
import json
import re
from pathlib import Path

from aramaic_core import AramaicCorpus, RootExtractor, hebrew_to_syriac

from .report import write_report
from .version import TABLES_VERSION

ROOT = Path(__file__).resolve().parent.parent
_SPLIT = re.compile(r"[\s.,:;()\[\]\"'״׳]+")


def tokenize(text: str) -> list[str]:
    return [w for w in _SPLIT.split(text) if w]


def load_overrides(path: Path) -> dict[str, tuple[str, str | None]]:
    out = {}
    with path.open(encoding="utf-8") as f:
        for r in csv.DictReader(f, delimiter="\t"):
            stem = (r.get("stem") or "").strip() or None
            out[r["surface"].strip()] = (hebrew_to_syriac(r["root"].strip()), stem)
    return out


def _write_atlas_csv(passages: list[dict], path: Path) -> None:
    """aramaic_core reads corpora as CSV: book_order,book,chapter,verse,reference,syriac."""
    with path.open("w", encoding="utf-8", newline="") as f:
        w = csv.writer(f)
        w.writerow(["book_order", "book", "chapter", "verse", "reference", "syriac"])
        for i, p in enumerate(passages):
            w.writerow([1, "Zohar", 1, i + 1, p["id"], p["text_ar"]])


def lemmatise(passages: list[dict], overrides: dict, data_dir: Path, tmp_dir: Path) -> list[dict]:
    tmp_dir.mkdir(parents=True, exist_ok=True)
    csv_path = tmp_dir / "zohar_atlas.csv"
    _write_atlas_csv(passages, csv_path)
    corpus = AramaicCorpus()
    corpus.add_corpus("zohar", "Zohar", str(csv_path))
    ex = RootExtractor(corpus, data_dir=str(data_dir))
    ex.build_index()
    tokens = []
    for p in passages:
        for pos, surface in enumerate(tokenize(p["text_ar"])):
            if surface in overrides:
                root, stem = overrides[surface]
                tokens.append(dict(passage_id=p["id"], position=pos, surface=surface, root=root,
                                   stem=stem, confidence=1.0, source="override"))
                continue
            rc = ex.lookup_word_root_with_confidence(surface)
            if rc is None:
                tokens.append(dict(passage_id=p["id"], position=pos, surface=surface, root=None,
                                   stem=None, confidence=0.0, source="none"))
            else:
                tokens.append(dict(passage_id=p["id"], position=pos, surface=surface, root=rc[0],
                                   stem=ex.lookup_word_stem(surface), confidence=float(rc[1]),
                                   source="aramaic_core"))
    return tokens


def main(argv=None) -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--raw", default=str(ROOT / "raw" / f"zohar.v{TABLES_VERSION}.json"))
    args = ap.parse_args(argv)
    raw = json.loads(Path(args.raw).read_text(encoding="utf-8"))
    overrides = load_overrides(ROOT / "seeds" / "zohar_overrides.tsv")
    work = ROOT / "work"
    toks = lemmatise(raw["passages"], overrides, ROOT / "vendor" / "atlas_roots", work / "tmp")
    with (work / "tokens.jsonl").open("w", encoding="utf-8") as f:
        for t in toks:
            f.write(json.dumps(t, ensure_ascii=False) + "\n")
    from collections import Counter
    low = Counter(t["surface"] for t in toks if t["confidence"] < 0.5)
    rows = [("tokens", len(toks)),
            ("with root", sum(1 for t in toks if t["root"])),
            ("override", sum(1 for t in toks if t["source"] == "override")),
            ("confidence ≥ 0.8", sum(1 for t in toks if t["confidence"] >= 0.8)),
            ("confidence < 0.5", sum(1 for t in toks if t["confidence"] < 0.5))]
    rows += [(f"low-conf #{i+1}: {s}", n) for i, (s, n) in enumerate(low.most_common(50))]
    write_report(work / "lemmatise.report.md", "lemmatise", rows)


if __name__ == "__main__":
    main()
```

NODES = {"ein_sof", "keter", "hokhmah", "binah", "hesed", "gevurah", "tiferet",
         "netzah", "hod", "yesod", "malkhut", "sitra_ahra"}
KINDS = {"person", "object", "quality", "event"}
PROCLITICS = set("ודבלכמש")


class SeedError(Exception):
    pass


@dataclass
class Symbol:
    id: str
    label_en: str
    label_es: str
    label_ar: str
    kind: str
    node: str
    aliases_surface: list[str]
    aliases_root: list[str]          # Syriac-script canonical roots
    states: dict[str, list[str]]     # label -> Hebrew-script roots (as written in seed)
    seed_source: str
    states_syriac: dict[str, list[str]] = field(default_factory=dict)


def _split(s: str) -> list[str]:
    return [x.strip() for x in (s or "").split(";") if x.strip()]


def _parse_states(s: str) -> dict[str, list[str]]:
    out = {}
    for part in (s or "").split("|"):
        part = part.strip()
        if not part:
            continue
        label, _, roots = part.partition(":")
        out[label.strip()] = [r.strip() for r in roots.split(",") if r.strip()]
    return out


def load_kinnuyim(path: Path) -> list[Symbol]:
    syms, seen = [], set()
    with path.open(encoding="utf-8") as f:
        for r in csv.DictReader(f, delimiter="\t"):
            if r["id"] in seen:
                raise SeedError(f"duplicate id {r['id']}")
            if r["node"] not in NODES:
                raise SeedError(f"{r['id']}: unknown node {r['node']}")
            if r["kind"] not in KINDS:
                raise SeedError(f"{r['id']}: unknown kind {r['kind']}")
            surf = _split(r["aliases_surface"])
            if not surf:
                raise SeedError(f"{r['id']}: no surface aliases")
            states = _parse_states(r.get("states", ""))
            syms.append(Symbol(
                id=r["id"], label_en=r["label_en"], label_es=r["label_es"], label_ar=r["label_ar"],
                kind=r["kind"], node=r["node"], aliases_surface=surf,
                aliases_root=[hebrew_to_syriac(x) for x in _split(r["aliases_root"])],
                states=states, seed_source=r["seed_source"],
                states_syriac={k: [hebrew_to_syriac(x) for x in v] for k, v in states.items()}))
            seen.add(r["id"])
    return syms


def strip_proclitics(surface: str) -> list[str]:
    out = [surface]
    s = surface
    for _ in range(2):
        if len(s) > 2 and s[0] in PROCLITICS:
            s = s[1:]
            out.append(s)
        else:
            break
    return out


def tag(tokens: list[dict], symbols: list[Symbol]) -> list[dict]:
    single: dict[str, list[str]] = {}       # alias word -> [symbol ids]
    multi: list[tuple[list[str], str]] = []  # (alias words, symbol id)
    by_root: dict[str, list[str]] = {}
    for s in symbols:
        for a in s.aliases_surface:
            words = a.split()
            if len(words) == 1:
                single.setdefault(a, []).append(s.id)
            else:
                multi.append((words, s.id))
        for r in s.aliases_root:
            by_root.setdefault(r, []).append(s.id)

    by_passage: dict[str, list[dict]] = {}
    for t in tokens:
        by_passage.setdefault(t["passage_id"], []).append(t)

    mentions = []
    for pid, toks in by_passage.items():
        toks.sort(key=lambda t: t["position"])
        surfaces = [t["surface"] for t in toks]
        for i, t in enumerate(toks):
            hit = False
            # multi-word first
            for words, sid in multi:
                cands = strip_proclitics(surfaces[i])
                if any(c == words[0] for c in cands) and surfaces[i + 1:i + len(words)] == words[1:]:
                    mentions.append(dict(symbol_id=sid, passage_id=pid, position=t["position"],
                                         matched_form=" ".join(words), via="surface"))
                    hit = True
            for c in strip_proclitics(t["surface"]):
                for sid in single.get(c, []):
                    mentions.append(dict(symbol_id=sid, passage_id=pid, position=t["position"],
                                         matched_form=c, via="surface"))
                    hit = True
            if not hit and t.get("root") and t["root"] in by_root:
                for sid in by_root[t["root"]]:
                    mentions.append(dict(symbol_id=sid, passage_id=pid, position=t["position"],
                                         matched_form=t["surface"], via="root"))
    mentions.sort(key=lambda m: (m["passage_id"], m["position"], m["symbol_id"]))
    return mentions


def main(argv=None) -> None:
    work = ROOT / "work"
    tokens = [json.loads(l) for l in (work / "tokens.jsonl").open(encoding="utf-8")]
    syms = load_kinnuyim(ROOT / "seeds" / "kinnuyim.tsv")
    m = tag(tokens, syms)
    with (work / "mentions.jsonl").open("w", encoding="utf-8") as f:
        for x in m:
            f.write(json.dumps(x, ensure_ascii=False) + "\n")
    from collections import Counter
    c = Counter(x["symbol_id"] for x in m)
    rows = [("mentions", len(m)), ("symbols with ≥1 mention", len(c)),
            ("symbols with 0 mentions", len([s for s in syms if s.id not in c]))]
    rows += [(f"top #{i+1}: {sid}", n) for i, (sid, n) in enumerate(c.most_common(30))]
    rows += [(f"zero: {s.id}", 0) for s in syms if s.id not in c]
    write_report(work / "tag.report.md", "tag", rows)


if __name__ == "__main__":
    main()
```

# pipeline/compute.py
"""Deterministic tables: co-occurrence, states, strata, surfaced passages, resolved counts."""
import argparse
import csv
import json
import math
from collections import Counter, defaultdict
from itertools import combinations
from pathlib import Path

from .report import write_report
from .tag import Symbol, load_kinnuyim
from .version import TABLES_VERSION

ROOT = Path(__file__).resolve().parent.parent


def load_strata(path: Path) -> list[dict]:
    rows = []
    with path.open(encoding="utf-8") as f:
        lines = [l for l in f if not l.startswith("#")]
    for r in csv.DictReader(lines, delimiter="\t"):
        rows.append(dict(volume=int(r["volume"]), from_folio=int(r["from_folio"]), from_side=r["from_side"],
                         to_folio=int(r["to_folio"]), to_side=r["to_side"], stratum=r["stratum"]))
    return rows


def _key(folio: int, side: str) -> int:
    return folio * 2 + (0 if side == "a" else 1)


def assign_strata(passages: list[dict], rows: list[dict]) -> dict[str, str]:
    out = {}
    for p in passages:
        k = _key(p["folio"], p["side"])
        s = "main"
        for r in rows:
            if r["volume"] == p["volume"] and _key(r["from_folio"], r["from_side"]) <= k <= _key(r["to_folio"], r["to_side"]):
                s = r["stratum"]
                break
        out[p["id"]] = s
    return out


def _symbols_by_passage(mentions: list[dict]) -> dict[str, set[str]]:
    d = defaultdict(set)
    for m in mentions:
        d[m["passage_id"]].add(m["symbol_id"])
    return d


def cooccurrence(mentions: list[dict]) -> list[dict]:
    sbp = _symbols_by_passage(mentions)
    n = len(sbp)
    single = Counter()
    pair = Counter()
    for syms in sbp.values():
        for s in syms:
            single[s] += 1
        for a, b in combinations(sorted(syms), 2):
            pair[(a, b)] += 1
    out = []
    for (a, b), c in sorted(pair.items()):
        pmi = math.log2((c / n) / ((single[a] / n) * (single[b] / n))) if n else 0.0
        out.append(dict(a=a, b=b, passages_together=c, pmi=round(pmi, 4)))
    return out


def detect_states(mentions: list[dict], tokens: list[dict], symbols: list[Symbol]) -> list[dict]:
    roots_by_passage = defaultdict(set)
    for t in tokens:
        if t.get("root"):
            roots_by_passage[t["passage_id"]].add(t["root"])
    sym = {s.id: s for s in symbols}
    seen = set()
    out = []
    for m in mentions:
        s = sym[m["symbol_id"]]
        for label, roots in s.states_syriac.items():
            if (s.id, label, m["passage_id"]) in seen:
                continue
            if roots_by_passage[m["passage_id"]] & set(roots):
                out.append(dict(symbol_id=s.id, state_label=label, passage_id=m["passage_id"]))
                seen.add((s.id, label, m["passage_id"]))
    out.sort(key=lambda x: (x["symbol_id"], x["state_label"], x["passage_id"]))
    return out


def _top_partners(symbol_id: str, cooc: list[dict], k: int = 3) -> list[str]:
    rows = [(c["b"] if c["a"] == symbol_id else c["a"], c["passages_together"])
            for c in cooc if symbol_id in (c["a"], c["b"])]
    rows.sort(key=lambda x: (-x[1], x[0]))
    return [r[0] for r in rows[:k]]


def surfaced_passages(symbol_id: str, mentions: list[dict], cooc: list[dict],
                      tokens_by_passage: dict[str, list[dict]], strata: dict[str, str], k: int = 6) -> list[str]:
    partners = set(_top_partners(symbol_id, cooc))
    score = Counter()
    for m in mentions:
        if m["symbol_id"] == symbol_id:
            score[m["passage_id"]] += 2
        elif m["symbol_id"] in partners:
            score[m["passage_id"]] += 1
    cands = [pid for pid in score if any(m["symbol_id"] == symbol_id and m["passage_id"] == pid for m in mentions)]
    dens = {pid: score[pid] / max(1, len(tokens_by_passage.get(pid, []))) for pid in cands}
    ranked = sorted(cands, key=lambda pid: (-dens[pid], pid))
    chosen, used_strata = [], set()
    for pid in ranked:                      # one per stratum first
        st = strata.get(pid, "main")
        if st not in used_strata:
            chosen.append(pid)
            used_strata.add(st)
        if len(chosen) == k:
            return chosen
    for pid in ranked:                      # then fill by density
        if pid not in chosen:
            chosen.append(pid)
        if len(chosen) == k:
            break
    return chosen


def resolve_counts(mentions: list[dict], cooc: list[dict], symbols: list[Symbol]) -> dict:
    sym = {s.id: s for s in symbols}
    # alias word -> symbols sharing it
    shared = defaultdict(set)
    for s in symbols:
        for a in s.aliases_surface:
            shared[a].add(s.id)
    support = defaultdict(int)             # (symbol, passage) -> partner support
    sbp = _symbols_by_passage(mentions)
    pt = {(c["a"], c["b"]): c["passages_together"] for c in cooc}
    for pid, syms in sbp.items():
        for s in syms:
            support[(s, pid)] = sum(pt.get(tuple(sorted((s, o))), 0) for o in syms if o != s)
    raw, resolved, passages = Counter(), Counter(), defaultdict(set)
    for m in mentions:
        s = m["symbol_id"]
        raw[s] += 1
        passages[s].add(m["passage_id"])
        rivals = shared.get(m["matched_form"], set()) - {s}
        if rivals and any(support[(r, m["passage_id"])] > support[(s, m["passage_id"])] for r in rivals):
            continue
        resolved[s] += 1
    return {s.id: dict(raw=raw[s.id], resolved=resolved[s.id], passages=len(passages[s.id])) for s in symbols}


def main(argv=None) -> None:
    work = ROOT / "work"
    raw = json.loads((ROOT / "raw" / f"zohar.v{TABLES_VERSION}.json").read_text(encoding="utf-8"))
    tokens = [json.loads(l) for l in (work / "tokens.jsonl").open(encoding="utf-8")]
    mentions = [json.loads(l) for l in (work / "mentions.jsonl").open(encoding="utf-8")]
    syms = load_kinnuyim(ROOT / "seeds" / "kinnuyim.tsv")
    strata = assign_strata(raw["passages"], load_strata(ROOT / "seeds" / "strata.tsv"))
    cooc = cooccurrence(mentions)
    tbp = defaultdict(list)
    for t in tokens:
        tbp[t["passage_id"]].append(t)
    out = dict(
        tables_version=TABLES_VERSION,
        cooccurrence=cooc,
        symbol_counts=resolve_counts(mentions, cooc, syms),
        states=detect_states(mentions, tokens, syms),
        strata=dict(sorted(strata.items())),
        surfaced={s.id: surfaced_passages(s.id, mentions, cooc, tbp, strata) for s in sorted(syms, key=lambda s: s.id)},
    )
    (work / "computed.json").write_text(json.dumps(out, ensure_ascii=False, indent=1, sort_keys=True), encoding="utf-8")
    write_report(work / "compute.report.md", "compute", [
        ("pairs", len(cooc)), ("states", len(out["states"])),
        ("strata", dict(Counter(strata.values()))),
        ("symbols with < 6 surfaced", sum(1 for v in out["surfaced"].values() if len(v) < 6)),
    ])


if __name__ == "__main__":
    main()
```

CREATE TABLE meta (key TEXT PRIMARY KEY, value TEXT NOT NULL);
CREATE TABLE passage (
  id TEXT PRIMARY KEY, volume INTEGER NOT NULL, folio INTEGER NOT NULL, side TEXT NOT NULL,
  para INTEGER NOT NULL, parasha TEXT NOT NULL, stratum TEXT NOT NULL,
  text_ar TEXT NOT NULL, verse_ref TEXT, token_count INTEGER NOT NULL
);
CREATE TABLE token (
  passage_id TEXT NOT NULL REFERENCES passage(id), position INTEGER NOT NULL,
  surface TEXT NOT NULL, root TEXT, stem TEXT, confidence REAL NOT NULL, source TEXT NOT NULL,
  PRIMARY KEY (passage_id, position)
);
CREATE TABLE symbol (
  id TEXT PRIMARY KEY, label_en TEXT NOT NULL, label_es TEXT NOT NULL, label_ar TEXT NOT NULL,
  kind TEXT NOT NULL, node TEXT NOT NULL, aliases TEXT NOT NULL,
  gloss_en TEXT, gloss_es TEXT, moves_en TEXT, moves_es TEXT, seed_source TEXT NOT NULL,
  count_raw INTEGER NOT NULL, count_resolved INTEGER NOT NULL, count_passages INTEGER NOT NULL
);
CREATE TABLE mention (
  symbol_id TEXT NOT NULL REFERENCES symbol(id), passage_id TEXT NOT NULL REFERENCES passage(id),
  position INTEGER NOT NULL, matched_form TEXT NOT NULL, via TEXT NOT NULL
);
CREATE INDEX mention_symbol ON mention(symbol_id);
CREATE INDEX mention_passage ON mention(passage_id);
CREATE TABLE cooccurrence (
  symbol_a TEXT NOT NULL, symbol_b TEXT NOT NULL, passages_together INTEGER NOT NULL,
  pmi REAL NOT NULL, tables_version TEXT NOT NULL, PRIMARY KEY (symbol_a, symbol_b)
);

```python
# pipeline/build.py
"""Write data/zohar.sqlite and data/tables.v{N}.json from the stage outputs."""
import json
import sqlite3
from datetime import datetime, timezone
from pathlib import Path

from .lemmatise import tokenize
from .report import write_report
from .tag import Symbol, load_kinnuyim
from .version import TABLES_VERSION

ROOT = Path(__file__).resolve().parent.parent
SCHEMA = (Path(__file__).parent / "schema.sql").read_text(encoding="utf-8")


def build(raw: dict, tokens: list[dict], mentions: list[dict], computed: dict,
          symbols: list[Symbol], out_sqlite: Path, out_json: Path) -> None:
    out_sqlite.parent.mkdir(parents=True, exist_ok=True)
    if out_sqlite.exists():
        out_sqlite.unlink()
    con = sqlite3.connect(out_sqlite)
    con.executescript(SCHEMA)
    strata = computed["strata"]
    con.executemany("insert into passage values (?,?,?,?,?,?,?,?,?,?)", [
        (p["id"], p["volume"], p["folio"], p["side"], p["para"], p["parasha"], strata.get(p["id"], "main"),
         p["text_ar"], p.get("verse_ref"), len(tokenize(p["text_ar"]))) for p in raw["passages"]])
    con.executemany("insert into token values (?,?,?,?,?,?,?)", [
        (t["passage_id"], t["position"], t["surface"], t["root"], t["stem"], t["confidence"], t["source"]) for t in tokens])
    counts = computed["symbol_counts"]
    con.executemany("insert into symbol values (?,?,?,?,?,?,?,?,?,?,?,?,?,?,?)", [
        (s.id, s.label_en, s.label_es, s.label_ar, s.kind, s.node, ";".join(s.aliases_surface),
         None, None, None, None, s.seed_source,
         counts.get(s.id, {}).get("raw", 0), counts.get(s.id, {}).get("resolved", 0), counts.get(s.id, {}).get("passages", 0))
        for s in symbols])
    con.executemany("insert into mention values (?,?,?,?,?)", [
        (m["symbol_id"], m["passage_id"], m["position"], m["matched_form"], m["via"]) for m in mentions])
    con.executemany("insert into cooccurrence values (?,?,?,?,?)", [
        (c["a"], c["b"], c["passages_together"], c["pmi"], TABLES_VERSION) for c in computed["cooccurrence"]])
    sym = {s.id: s for s in symbols}
    con.executemany("insert into state values (?,?,?,?)", [
        (s["symbol_id"], s["state_label"], ",".join(sym[s["symbol_id"]].states[s["state_label"]]), s["passage_id"])
        for s in computed["states"]])
    con.executemany("insert into surfaced values (?,?,?)", [
        (sid, i, pid) for sid, pids in computed["surfaced"].items() for i, pid in enumerate(pids)])
    con.executemany("insert into meta values (?,?)", [
        ("tables_version", TABLES_VERSION),
        ("built_at", datetime.now(timezone.utc).isoformat(timespec="seconds")),
        ("source_revids", json.dumps([p["revid"] for p in raw["pages"]])),
    ])
    con.commit()
    con.close()
    j = dict(computed)
    j["tables_version"] = TABLES_VERSION
    j["symbols"] = [dict(id=s.id, label_en=s.label_en, label_es=s.label_es, label_ar=s.label_ar, kind=s.kind,
                         node=s.node, aliases=s.aliases_surface, seed_source=s.seed_source) for s in symbols]
    out_json.write_text(json.dumps(j, ensure_ascii=False, indent=1, sort_keys=True), encoding="utf-8")


def main(argv=None) -> None:
    work = ROOT / "work"
    raw = json.loads((ROOT / "raw" / f"zohar.v{TABLES_VERSION}.json").read_text(encoding="utf-8"))
    tokens = [json.loads(l) for l in (work / "tokens.jsonl").open(encoding="utf-8")]
    mentions = [json.loads(l) for l in (work / "mentions.jsonl").open(encoding="utf-8")]
    computed = json.loads((work / "computed.json").read_text(encoding="utf-8"))
    syms = load_kinnuyim(ROOT / "seeds" / "kinnuyim.tsv")
    build(raw, tokens, mentions, computed, syms, ROOT / "data" / "zohar.sqlite", ROOT / "data" / f"tables.v{TABLES_VERSION}.json")
    write_report(ROOT / "data" / "report.md", f"build {TABLES_VERSION}", [
        ("passages", len(raw["passages"])), ("tokens", len(tokens)), ("mentions", len(mentions)),
        ("symbols", len(syms)), ("pairs", len(computed["cooccurrence"])),
        ("tokens with root", sum(1 for t in tokens if t["root"])),
    ])


if __name__ == "__main__":
    main()
```

# pipeline/run_all.py
"""Run every stage in order. fetch is cached; pass --refetch to clear the cache."""
import argparse
import shutil
from pathlib import Path

from . import build, compute, fetch, lemmatise, tag

ROOT = Path(__file__).resolve().parent.parent


def main(argv=None) -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--only", type=int, default=None)
    ap.add_argument("--refetch", action="store_true")
    a = ap.parse_args(argv)
    if a.refetch:
        shutil.rmtree(ROOT / "raw" / "cache", ignore_errors=True)
    fetch.main(["--only", str(a.only)] if a.only else [])
    lemmatise.main([])
    tag.main([])
    compute.main([])
    build.main([])


if __name__ == "__main__":
    main()
